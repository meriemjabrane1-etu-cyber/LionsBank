## 💡 Key Features Explained

### Feature 1: Create Guarantee
User provides:
- Amount to guarantee
- Duration (7, 14, 30 days, etc.)
- Payee details

System:
- Freezes amount in account
- Generates verification code
- Returns code to user
- Logs in audit trail

Beneficiary:
- Receives code
- Can verify without login
- Sees guarantee is real

### Feature 2: Auto-Release
When expiration time passes:
- Job runs every 5 minutes
- Finds expired reservations
- Releases frozen funds
- Updates guarantee status
- Amount available again

### Feature 3: Suspicious Activity
System tracks:
- Multiple failed verifications
- Attempts from same IP
- Attempts on same code
- Flags suspicious patterns
- Logged for investigation
